# Literature Review Copilot

An AI-assisted research environment for organising, searching, analysing, and reviewing academic literature.

Literature Review Copilot was developed to support literature-intensive research workflows by bringing document management, structured organisation, literature analysis, and AI-assisted research into a single interface.

The application is designed particularly with doctoral and academic research workflows in mind.
